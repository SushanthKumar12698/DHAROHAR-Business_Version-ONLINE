# DHAROHAR Business — iPhone (iOS) Install Guide (Free & Never Expires)

1. Create a free GitHub repository (e.g., `dharohar-business-ios`) and upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, and `icons/`).
2. In your GitHub repo, go to **Settings -> Pages -> Build and deployment -> Branch: main / (root)** -> click **Save**.
3. Open the generated `https://<your-username>.github.io/dharohar-business-ios/` link in **Safari** on your iPhone.
4. Tap the **Share (↑)** button at the bottom of Safari -> tap **Add to Home Screen** -> tap **Add**.

DHAROHAR Business will now appear on your iPhone Home Screen with its app icon, open full-screen without Safari bars, work 100% offline, and never expire!
